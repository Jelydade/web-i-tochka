# Сайт услуг по созданию сайтов

Новый проект личного сайта-портфолио и страницы услуг.

## План по этапам

1. Позиционирование и целевая аудитория.
2. Структура главной страницы.
3. Визуальное направление и первый экран.
4. Портфолио и описание услуг.
5. Форма заявки и контакты.
6. Адаптивность, проверка и публикация.

## Запуск

```bash
npm install
npm run dev
```
